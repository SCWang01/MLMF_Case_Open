# Sensitivity-design inputs

The ten `data_*.json` records contain the sampled price/resource factors, the random seed and the 32 coalition values for each perturbation of the five-DER physical inputs. The COPT equilibrium sweep uses these fixed market inputs. `witnesses.json` contains the 2,694 exact quote witnesses, keyed by original design row parameters. The independent verifier uses rational best responses to check each witness. The 15 near-zero configurations refer to the geometric certificates under `ancillary/certificates/`.

Run `python sensitivity/build_design.py` to regenerate `sensitivity/design_rebuilt.json`, or supply `--output` for another path. With Python 3.10, the resulting 384 market records and 14,288 design rows reproduce the released `design.json` byte for byte. Python 3.12 changed floating-point summation and can give small differences in the last digits of the generated coefficients. Use the released `design.json` with any supported environment when running the COPT sweep on the frozen coefficients.

The optional `original_dispatch/` reproduces the historical data-generation step for the ten perturbation tables. Run `python sensitivity/design_inputs/original_dispatch/resimulate.py 1` for one worker. This optional operation needs gurobipy and a licensed Gurobi installation. It writes fresh outputs under `original_dispatch/resimulated/`. No Gurobi installation is needed to use the supplied tables, rebuild the design, or run the paper's COPT equilibrium sweep. Runtime and floating-point optimizer outputs may differ between solver versions.
